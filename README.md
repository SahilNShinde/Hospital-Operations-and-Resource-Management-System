# 🏥 Hospital Operations and Resource Management System

A desktop application designed to automate administrative workflows, streamline patient lifecycle management, and track real-time resource allocations for healthcare institutions.

## 🚀 Key Features

* **Add New Patient:** Streamlines patient admissions by capturing identification details, medical diagnosis, contact info, and dynamic room allocation.
* **Update Patient Details:** Allows receptionists to update existing patient records, admission timestamps, deposit amounts, and pending bill balances.
* **All Patient Info Directory:** Centralized dashboard view displaying complete patient records, assigned room numbers, admission time, and payment status.
* **Room Availability Tracker:** Live status monitor across General Ward, Private Rooms, and ICU Beds with dynamic pricing and occupancy indicators.
* **Patient Discharge & Checkout:** Computes checkout times, validates pending bills, and automatically frees up room availability upon discharge.
* **All Employee Info:** Centralized staff database detailing employee names, roles, contact numbers, and salary information.
* **Department Information:** Quick-lookup directory for hospital departments and emergency contact lines.
* **Ambulance Info:** ambulance detailing like driver names, his gender, car name/no.

* **Database Management:** MySQL
* **Database Connectivity:** JDBC (`mysql-connector-java`)
* **IDE:** IntelliJ IDEA
